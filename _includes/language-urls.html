{% comment %} Логика переключения языковых версий: 1. Этот include вычисляет ссылки на языковые версии страницы. 2. Для каждой страницы вычисляются две ссылки: ru_url и en_url. 3. По умолчанию используется fallback: ru_url = "/"; en_url = "/en/". 4. Для главной страницы: "/" переключается на "/en/"; "/en/" переключается на "/". 5. Для страницы содержания: "/contents" переключается на "/en/contents"; "/en/contents" переключается на "/contents". 6. Для постов: если текущая страница русская, среди site.posts ищется английский пост с таким же slug; если найден, en_url ведёт на найденный post.url; если не найден, en_url остаётся "/en/"; если текущая страница английская, среди site.posts ищется русский пост с таким же slug; если найден, ru_url ведёт на найденный post.url; если не найден, ru_url остаётся "/". 7. Для тегов, стран и категорий: если у страницы есть page.tag, page.country или page.category, такой же label ищется в данных другого языка; если пара найдена, ссылка ведёт на "/en/{{ label }}" или "/{{ label }}"; если пара не найдена, остаётся fallback на главную выбранного языка. 8.
